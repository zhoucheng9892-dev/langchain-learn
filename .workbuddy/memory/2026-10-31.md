### 关键技术结论（下次别重新踩）
- 环境：langchain 1.4.7 / langchain-core 1.7.3 / langgraph 1.2.19 / langchain-deepseek 1.1.1，Python 3.11（uv 的 .venv）。
- DeepSeek API 模型名只有 `deepseek-flash` / `deepseek-v4-pro`；平台展示名 `deepseek-v4.1-flash` 会 400。已在 src/langchain_learn/llm.py 做别名映射。
- 思考模式（默认开启）不支持强制 tool_choice：
  - `with_structured_output` 会 400 "Thinking mode does not support this tool_choice"
  - agent `response_format=Pydantic` 会走 ProviderStrategy → 400 "This response_format type is unavailable now"
  - 解法：`ChatDeepSeek(reasoning_effort="none")` + `ToolStrategy(Schema)`
- 思考模式下 max_tokens 太小会让 content 为空（finish_reason=length，token 全被 reasoning 吃掉）。
- Windows：一个进程多次 asyncio.run() 复用 httpx client 会报 "Event loop is closed"，合并到单个事件循环即可。
- `trim_messages` 裁剪会丢历史导致答错；`SummarizationMiddleware(trigger=("messages",8), keep=("messages",2))` 能保住全部关键约束。
- HITL：需 checkpointer；`result["__interrupt__"]` → `Command(resume={"decisions":[{"type":"approve|reject|edit|respond"}]})`；edit 用 `edited_action`。
- `graph.get_graph().draw_ascii()` 需要 grandalf，未装则改为打印 nodes/edges。
- InMemoryVectorStore 的 cosine 相似度需要 numpy。
- DeepSeek 无 embedding API，RAG 示例用自实现字符 bigram 哈希 embedding（src/langchain_learn/embeddings.py），生产换 bge-m3。

### 结构约定
- 公共代码放在已安装包 src/langchain_learn（editable），示例用 `from langchain_learn import get_model`，避免 sys.path hack。
- `run_all.py` 可批量回归：`uv run python run_all.py [ch07]`。
